1. Nombres premiers de 500 chiffres

Environ 1 nombre sur 1151 de cette taille est premier. Le test de Miller-Rabin le vérifie en quelques millisecondes.

10⁴⁹⁹ ≤ p, q < 10⁵⁰⁰

2. Module n et indicatrice d'Euler

Le produit n = p × q a 1000 chiffres. φ(n) compte les entiers premiers avec n.

n = p × q
φ(n) = (p − 1)(q − 1)

3. Clés publique et privée

On prend e = 65537. La clé d est l'inverse de e modulo φ(n) (Euclide étendu).

e × d ≡ 1 (mod φ(n))

4. Chiffrement et déchiffrement

Le théorème d'Euler garantit que Cᵈ mod n redonne exactement M.

C = Mᵉ mod n
M = Cᵈ mod n

5. Pourquoi est-ce difficile à casser ?

Pour trouver d, un attaquant doit connaître φ(n), donc factoriser n. Le meilleur algorithme connu, le crible GNFS, est sous-exponentiel : il reste hors de portée pour 1000 chiffres.

GNFS : exp((c + o(1)) · (ln n)¹ᐟ³ · (ln ln n)²ᐟ³)
